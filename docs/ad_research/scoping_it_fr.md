# Italy and France anaerobic digestion (AD) / biogas / biomethane — data source scoping

Prepared: 2026-09-25. Scope: Italy and France. All AD types (agricultural/manure, biowaste, industrial, sewage-sludge). Goal: identify data sources for a plant-level inventory to support AD+CCS siting work, replacing the current few hand-placed regional points for these countries on the BiCRS map.

**Status of this document: scoping only. No inventory has been built.** Every source below was opened directly (curl/API for data portals, WebFetch for narrative pages) unless explicitly marked UNVERIFIED. Two access blockers dominate this pass and should be read as the headline finding before the detail: **GSE's entire web estate (gse.it, atla.gse.it) returned HTTP 403 (Akamai WAF) to every scripted request**, so Italy's single most important named source (Atlaimpianti) could not be directly verified; and **Géorisques (georisques.gouv.fr) and its BRGM WFS mirror were completely unreachable** from this environment (connection refused / WAF rejection), so France's most promising source for precise plant coordinates (ICPE rubrique 2781) could only be checked against a stale 2019/2021 third-party mirror. Both should be retried by a human with a browser session / different network before being written off.

All URLs, raw API calls, sample records, and additional per-source detail beyond what's summarized below were captured during research in session scratch notes; those notes are ephemeral (not part of the repo) and are not linked here since the path won't persist — this report is the durable record.

## 2. Recommended primary source, gap-fillers, and dedup strategy

**No verified, downloadable, plant-level national source for Italy could be confirmed in this pass.** GSE — which hosts both Atlaimpianti (the atlas) and the biomethane graduatorie (the incentive registers) — returned HTTP 403 (Akamai WAF) to every scripted request tried, including a bare HEAD request on a PDF. This is the single biggest blocker in this scoping pass and should be escalated before any further build work: **a human needs to manually export data via Atlaimpianti's in-browser query/download tool (or GSE needs to be asked directly for a bulk extract)**; a headless-browser session with real cookies may also get past the WAF where curl/WebFetch cannot.

Pending that, the practical near-term recommendation is:
1. **Regional Arpa "Impianti a bioenergia" layers as the plant-level backbone**, starting from the confirmed-working Emilia-Romagna model (Arpae, CC BY 4.0, 268 biogas records with WGS84 coordinates, feedstock type, capacity, status, and a `ID_GSE` field that cross-references back to GSE's internal plant ID). **Action item: check whether the equivalent regional environment agencies (ARPA Lombardia, ARPAV Veneto, Arpa Piemonte) publish the same "Impianti a bioenergia" product** — not confirmed this pass, but plausible given they share a common national Arpa/SNPA data-model convention; if so this could become a genuine multi-region plant-level layer without needing GSE at all.
2. **GSE PNRR/DM biomethane graduatorie (via mirror pages, e.g. CIB, MASE)** as a secondary, capacity/count-only cross-check for the biomethane-specific subset — not plant-coordinates, but useful for validating totals and for eventually geocoding by comune once the underlying lists are obtained.
3. **dati.gov.it/RNDT provincial hits (confirmed: Rovigo, Torino metro)** as opportunistic long-tail gap-fillers, to be resolved province-by-province.
4. Treat **Terna GAUDÌ and CIB's own plant-count claims as unusable for plant-level work** (GAUDÌ is credential-gated; CIB publishes membership/advocacy stats, not a plant register).

**Dedup strategy**: the Arpae Emilia-Romagna dataset's `ID_GSE` field and `COD_COM` (ISTAT comune code) are the two fields to standardize on across regions and against GSE data once/if GSE access is obtained — `ID_GSE` is a direct join key back to the GSE registry that every other source (graduatorie, Atlaimpianti) should also carry, and `COD_COM` is the standard ISTAT geography key for joining to any comune-level administrative or census data. Absent GSE access, plant name + comune (fuzzy match) is the fallback join key across regional/provincial sources.

## 3. Validation totals

- **Terna, "Dati statistici sull'energia elettrica in Italia 2024" (verified, primary PDF, downloaded and parsed directly), end-2024 national totals:**
  - Biogas electricity-only: 644 plants, 456,490 kW.
  - Biogas CHP: 1,660 plants, 1,016,388 kW.
  - **Total biogas electricity: 2,304 plants, 1,472,878 kW (≈1,473 MWe).**
  - 2024 gross production: 7,495.8 GWh total biogas electricity.
  - **Caveat on the by-feedstock breakdown**: Table 21 also splits each of the two rows (electricity-only, CHP) by feedstock subtype (rifiuti / fanghi / deiezioni animali / attività agricole e forestali), and the MW and GWh figures for those subtypes sum exactly to the totals above (confirming capacity/production are allocated per fuel correctly). **The plant-count subtypes do not sum to the row totals** (e.g. electricity-only subtypes sum to 666 vs. a reported row total of 644; CHP subtypes sum to 1,784 vs. 1,660) — this means multi-feedstock plants are counted once under each fuel they use, so a per-feedstock plant count (e.g. "agricultural plants" or "sewage-sludge plants") would double-count some sites. **Only the overall total (2,304 plants), and the MW/GWh figures at any level of breakdown, should be cited as firm numbers**; a species/feedstock-specific plant count is not safely derivable from this table.
  - Note: biomethane-only plants (no electricity output) are **not** included in these Terna/GAUDÌ-derived counts.
- **GSE PNRR biomethane bandi (verified via mirror pages, not the primary GSE files):** 5th bando ranking — 298 projects, 122,842.20 Smc/h combined capacity; an earlier bando (dated 24 Nov 2023) — 51 projects, 25,881 Smc/h, cumulative 86 projects across the first two procedures.
- **CIB homepage (verified, undated):** 1,151 consortium members, 458 MW installed (membership statistic, not a national plant count).
- **ISPRA IIR 2026 (verified, primary PDF), Table 6.10:** national AD feedstock 36,504,140 t in 2024, of which 16,749,504 t (46%) is animal manure.
- **GSE's own annual "Rapporto Statistico — Energia da FER in Italia" series (the most likely source of an authoritative national biogas plant-count/MW/GWh total) could NOT be obtained** — every gse.it URL, including this exact PDF filename found via search indexing (`Rapporto Statistico GSE - Energia da FER in Italia - anno 2023.pdf`), returned HTTP 403. **This is the single biggest validation gap for Italy**; recommend a manual browser download as a follow-up.
- The oft-cited secondary figure "2,000+ biogas plants nationally, ~1,014 MW agricultural capacity, ~7 TWh" is **broadly corroborated in order of magnitude** by the directly-verified Terna figures above (2,304 plants / 1,473 MWe / 7,496 GWh, all-biogas, end-2024) but should be cited to Terna specifically, not to the unverified secondary claim.

## 4. Manure-to-AD findings

Primary verified source: **ISPRA, "Italian Emission Inventory 1990–2024, Informative Inventory Report 2026"** (Rapporti ISPRA 426/2026, ISBN 978-88-448-0335-3, published April 2026) — note this is the LRTAP/NECD air-pollutant inventory, not the UNFCCC GHG NIR, though the companion GHG report (NID 2025) was also opened and gives a consistent figure (below).

- **Cattle (dairy cattle category, Table 6.5, p.157, quoted verbatim):** "The study estimated that in 2020 19% of cattle manure would be sent to anaerobic digestion... in 2010, 1% of manure went to digesters... in 2013 these values become 15%... This trend was assumed to be based on the exponential growth in the last ten years of anaerobic digesters." The 19% figure is **held constant from 2020 through 2024** (not re-estimated annually), based on a 2018 CRPA study.
- **Swine (p.~159, quoted verbatim):** "the study estimated that in 2020 3% of swine manure would be sent to anaerobic digestion... in 2010 and 2013 the percentage of manure sent to digesters remains at 3%."
- **National total feedstock (Table 6.10, p.164):** animal manure = 16,749,504 t of 36,504,140 t total AD feedstock in 2024 (**46%**), up from 1,766,348 t of 6,513,271 t in 2010.
- **Cross-check against the GHG inventory (NID 2025, "Italian Greenhouse Gas Inventory 1990–2023," Rapporti ISPRA 411/2025), Section 5.3 "Manure management (3B)":** states verbatim: "For the year 2023 this amount is equal to about 15 million tons and that is **46%** of the total amount of feed treated in anaerobic digesters" — same headline share (46%), though the absolute manure tonnage differs by ~10% from the IIR's 2023 figure (16.52 Mt IIR vs. ~15 Mt NID) — **flag both figures with their report and vintage rather than merging them**; likely a between-report recalculation, not an error. (Exact page number not pinned down with confidence — two independent extraction passes disagreed, one citing ~p.237 and one p.219 — cite the section title, not a page, until re-confirmed.) The NID also confirms ISPRA's own AD activity data are sourced from **Terna** (biogas production) and **GSE** (biomethane production, disaggregated by agricultural-organic substrate) — reinforcing that those two registries are the underlying primary data, even though both blocked scripted access in this pass.
- **Caveat**: the species-level shares (19% cattle, 3% swine) are CRPA-modeled assumptions from a single 2018 study extrapolated forward, not annually resurveyed — treat as a structural estimate, not a measured annual statistic.

## 2. Recommended primary source, gap-fillers, and dedup strategy

**Recommended primary source: ODRÉ (Opendatasoft portal, odre.opendatasoft.com)**, specifically two of its datasets used together:
1. `points-dinjection-de-biomethane-en-france` (biomethane injection sites, 855 records, has approximate coordinates, Licence Ouverte v2.0) — the only national dataset with any coordinate field.
2. `registre-national-installation-production-stockage-electricite-agrege` (biogas/biomasse electricity installations, 1,116 AD-relevant installations ≈605.6 MW, no coordinates but has INSEE commune code) — covers the CHP/electricity-only side of the fleet that the injection dataset misses entirely.

GRDF's own opendata portal (`opendata.grdf.fr`) publishes the same underlying injection registry as ODRÉ dataset 1 — confirmed by a matching stable ID (`id_unique_projet`/`id` = 170 resolves to the identical named project in both) — so it should be treated as a redundant mirror, not an independent second source, except for its useful `site`-typology facet (Agricole autonome / Agricole territorial / Station d'épuration / Industriel territorial / ISDND / Déchets ménagers), which is a cleaner feedstock-type breakdown than anything in the ODRÉ schema.

**Gap-fillers, in priority order:**
1. **Géorisques ICPE rubrique 2781** — the only route to precise (not commune-approximated) coordinates and to plants outside the two grid-connection registries (e.g. off-grid/heat-only farm digesters, which CITEPA's 1,412-methaniser count suggests are a real, non-trivial population). **Currently unreachable from this environment; must be retried from a different network/IP before being ruled out** — this is a genuine access blocker, not a confirmed absence of data.
2. **AILE / Bretagne-Environnement CSV** — a real, working, plant-level, open-licence regional cross-check (Brittany only). Worth checking whether other regional observatories (e.g. AILE's own reach into Pays de la Loire, or equivalents in other regions) publish similar CSVs.
3. **SINOE (ADEME)** — not currently usable (Cloudflare-blocked, and the one geolocated export findable elsewhere is 6+ years stale). Would need a direct ADEME data request (`admin.sinoe@ademe.fr`), not scripted access.

**Dedup strategy**: `id_unique_projet` (ODRÉ injection dataset) = `id` (GRDF injection dataset) = `id` (ODRÉ annual-production dataset) is a **confirmed shared key** across all three injection-side views — treat them as one registry, not additive. There is **no shared ID field** between the injection registry and the electricity registre (`registre-national-installation-production-stockage-electricite-agrege`); a plant doing both CHP and partial injection could appear in both under different site names. Recommended join key across that boundary, and eventually against Géorisques once reachable: **commune (INSEE code) + fuzzy name match**, following the approach a third-party open-source project (`ahdgn/biomethane-france`, found via search, **not independently verified**) reportedly already attempted — matching ~390 of ~904 rubrique-2781 sites to ODRÉ by commune+name and defaulting the rest to commune centroids. This is a plausible starting method to evaluate, not a verified result to cite as-is.

**Important caveat on the name-matching approach, confirmed directly (not from a secondary source)**: querying the electricity registre live (`.../records?where=codecombustible='B.MET' and nominstallation='Confidentiel'&limit=0`) returns **336 of 975 B.MET rows (34.5%) with `nominstallation` redacted to the literal string "Confidentiel"** for commercial-confidentiality reasons — the capacity, commune, and dates on those rows are otherwise fully populated. **Name-based fuzzy matching will silently fail for roughly a third of biogas-electricity installations.** The fallback join key for that subset needs to be **commune (INSEE code) + capacity (`puismaxinstallee`) + commissioning date (`datemiseenservice`)**, accepting a real residual ambiguity risk when a commune hosts more than one similarly-sized plant.

## 3. Validation totals

- **SDES, biogaz électricité, T1 2026 (verified, latest edition, quoted verbatim, fetched directly, published 29 May 2026):** "1 121 installations produisant de l'électricité à partir de biogaz" connected to the network as of 31 March 2026; "583 MW" total installed capacity; "718 GWh lors du premier trimestre 2026" production; "75 projets en file d'attente" totaling "56 MW" in the connection queue; cumulative new capacity since 1 Jan 2025 is only 3 MW, vs. an average of 11 MW/quarter installed in 2019 (sector slowdown). (The prior T3 2025 edition, published 27 Nov 2025, reported 1,105 installations / 576 MW as of 30 Sept 2025 — superseded, kept here only for the cross-check below.)
- **SDES, biométhane injecté, T2 2026 (verified, latest available, quoted/paraphrased):** 837 installations injecting biomethane; total injection capacity **16.2 TWh/an** (+3% vs. end-2025); 431 GWh/an of new capacity commissioned in H1 2026 (−33% y/y); methanisation units = **91%** of total park capacity (rest is landfill gas/sewage sludge/other biogas); pipeline of **1,357 projects, 23.4 TWh/an** (+25% vs. end-2025). As of 30 June 2026.
- **ODRÉ registre national, current snapshot (verified, direct API count):** 1,116 biogas-relevant (B.MET+B.STO+B.EPU) electricity installations, ≈605.6 MW, as of 31 July 2026 — a few months later than, and moderately higher than, SDES's 583 MW/1,121-installation T1 2026 figure (31 March 2026), consistent with the small ongoing growth SDES itself describes. At an earlier, exactly-matched snapshot date (31 Dec 2024), the same ODRÉ registre's summed B.MET capacity (576,623 kW ≈ 576.6 MW) matches the prior SDES T3 2025 bulletin's 576 MW almost exactly — a genuine, computed consistency check between two independently-fetched sources at the same reference date.
- **CITEPA, Secten 2026, p.451 (verified, quoted verbatim):** "En 2024, on dénombre 1412 méthaniseurs agricoles (à la ferme ou collectifs)" — larger than either grid-connection registry, implying a real population of off-grid/heat-only on-farm digesters invisible to ODRÉ/GRDF.
- **AILE, Brittany, Sept 2025 (verified):** 281 AD units (263 agricultural), 1.9 TWh primary energy, 280 GWh electric + 370 GWh thermal, 1,020 GWh PCS biomethane.
- **Take-away**: the three independently-verified national/regional "how many AD plants" figures — 855 (injection registry), 1,116 (electricity registry), 1,412 (CITEPA agricultural methanisers) — are not directly additive (different, overlapping universes) but are broadly consistent with a French AD fleet in the **roughly 1,000–1,500 plant range** as of 2024–2026, with a residual off-grid/heat-only population on top that no national registry currently captures.

## 4. Manure-to-AD findings

Primary source: **CITEPA, Rapport Secten 2026, p.451** (Centre interprofessionnel technique d'études de la pollution atmosphérique — compiler of France's national GHG/air-pollutant inventory), quoted verbatim:

> "Actuellement dans l'inventaire national des émissions de gaz à effet de serre publié par le Citepa, la méthanisation des déjections animales est prise en compte en tant que technique de réduction des émissions de méthane (CH4) : les tonnages de déjections méthanisées, centralisées ou à la ferme, sont estimés en croisant plusieurs données (base SINOE, ADEME, données de constructeurs, observatoires régionaux…) et les émissions réduites grâce à la méthanisation sont calculées au niveau de la gestion des déjections pour le cheptel bovin et porcin uniquement. Il faut noter que les demandes de construction de nouvelles unités de méthanisation sont en croissance forte. En 2024, on dénombre 1412 méthaniseurs agricoles (à la ferme ou collectifs)."

Key findings and caveats:
- **No explicit percentage of manure sent to AD was located** anywhere in the Secten 2026 narrative text (all occurrences of "déjections"/"effluents" were searched). The report gives the **count of methanisers (1,412 in 2024)** and the estimation methodology, but the quantified tonnage/percentage would sit in CITEPA's underlying CRF (Common Reporting Format) tables — e.g., a manure-management-system share table analogous to ISPRA's Table 6.5/6.6 for Italy — submitted as part of the National Inventory Report (NIR/NID) to the UNFCCC, a separate document from Secten.
- **That NIR/NID document was not located this pass**: citepa.org's own landing page states the latest listed edition is "NID REPORT ED. 2025, updated 16/05/2025" with no direct download link on that page; two plausible archive URLs (following the apparent naming pattern of `ressources.citepa.org/historiques/ccnucc/`) both returned HTTP 404. Per the no-fabrication rule, guessing was stopped rather than continued — **the archive index itself (`ressources.citepa.org/historiques/ccnucc/`) should be browsed directly in a follow-up pass**, not guessed at.
- **Scope caveat directly from the quote**: CITEPA's manure-to-AD emission-reduction accounting is explicitly restricted to **bovine and porcine manure management only** ("pour le cheptel bovin et porcin uniquement") — poultry and other livestock manure sent to AD is not covered by this specific calculation.
- **Coverage-gap cross-check**: 1,412 agricultural methanisers (2024) exceeds both the ~800 sites with metered 2025 injection production (ODRÉ) and the AD-relevant subset of the ~1,116 electricity installations — consistent with a meaningful population of off-grid/heat-only on-farm digesters not visible in either grid-connection registry, though unlikely to be large or attractive AD+CCS retrofit candidates given their small typical scale.

**Italy**

2. Whether other regions' environmental agencies (ARPA Lombardia, ARPAV Veneto, Arpa Piemonte) publish an "Impianti a bioenergia" layer equivalent to Emilia-Romagna's is **unconfirmed** — the single highest-value next step for Italy, since that one dataset (coordinates + feedstock type + capacity + status + GSE cross-reference ID) is exactly the schema needed.
3. Terna/GAUDÌ is very likely credential-gated (inferred from document titles, not a confirmed statement) — treat as unusable without a data-sharing agreement.
4. The two ISPRA reports (IIR 2026, NID 2025) give the same 46% national manure-share-of-AD-feedstock headline but differ by ~10% in absolute tonnage for the same year (2023) — cite each with its own report name and vintage, don't merge them into one number.
5. Lombardia's open-data portal, contrary to the original brief's assumption, currently has **no** dedicated biogas dataset (verified negative) — don't rely on that assumption downstream.

**France**
1. **Géorisques (georisques.gouv.fr) was completely unreachable from this environment** — via both direct API and its BRGM WFS mirror, on repeated attempts, while every other French source (data.gouv.fr, SDES, CITEPA, GRDF, AILE) was reachable fine. Retry from a different network before concluding it's unusable.
2. ODRÉ's only coordinate field (on the injection dataset) is **explicitly, verbatim, described by the publisher as deliberately approximated** for statistical-secrecy reasons — do not treat it as a precise site pin for AD+CCS feasibility siting without a secondary confirmation (e.g., against Géorisques once reachable).
